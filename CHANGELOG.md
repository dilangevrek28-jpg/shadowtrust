# Changelog

All notable ShadowTrust changes are documented here.

## 0.1.0 — 2026-10-26

### Added

- Strict versioned security-event contracts and synthetic banking corpus.
- Explainable rule engine with trust timeline, contradiction detection,
  adaptive response recommendations, evidence IDs, and bounded risk scoring.
- Deterministic corpus evaluation with precision, recall, false-positive rate,
  detection latency, step-up counts, JSON reporting, and CI quality gates.
- SQLite/PostgreSQL persistence, Alembic migrations, idempotent ingestion, and
  out-of-order event protection.
- Protected FastAPI ingestion, analyst, health, timeline, decision-replay,
  case-management, and Prometheus endpoints.
- Append-only analyst case audit history with optimistic concurrency control.
- Structured JSON logs, request correlation, body limits, security headers,
  role-separated API keys, and process-local rate limiting.
- Responsive React analyst console with demo mode, risk/case filters,
  investigation trace, case workflow, and decision replay.
- PostgreSQL, API, non-root Nginx, Prometheus, and Grafana Compose stack with
  scoped secrets, starter alerts, and provisioned dashboard.
- Cross-version backend CI, frontend CI, container builds, weekly dependency
  audits, security policy, contribution rules, and evaluation limitations.
